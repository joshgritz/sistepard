3. Descripcion del servicio

SISTEPARD es una plataforma electoral digital disenada para la gestion interna de partidos politicos en Republica Dominicana. El servicio incluye:

  • Gestion del padron de militantes y dirigentes.
  • Administracion de estructuras politicas por zona, municipio y sector.
  • Generacion y verificacion de actas electronicas con codigo QR.
  • Herramientas para planificar y ejecutar elecciones internas.
  • Dashboard en tiempo real con resultados y reportes.
  • Gestion documental: constituciones, estatutos, reglamentos, planes operativos y financieros.

4. Arquitectura multi-tenant

SISTEPARD opera bajo un modelo multi-tenant, donde cada partido politico tiene su propia instancia aislada. Esto significa que:

  • Datos separados: Cada partido tiene su propia base de datos, configuracion y usuarios. No hay comparticion de datos entre partidos.
  • Configuracion independiente: Cada instancia tiene su propio archivo de configuracion (config.json) con colores, logo y contenido legal localizable.
  • Aislamiento de seguridad: Las politicas Row Level Security (RLS) garantizan que cada usuario solo pueda acceder a los datos de su propio partido.
  • Dominio compartido: Todas las instancias operan bajo el mismo dominio (sistepard.com) pero con configuracion aislada.

5. Elegibilidad

Para utilizar SISTEPARD, debes cumplir con los siguientes requisitos:

  • Ser mayor de 18 anos de edad.
  • Ser ciudadano dominicano o residente permanente en Republica Dominicana.
  • Ser militante activo del partido politico registrado en la plataforma.
  • Poseer una cedula de identidad valida.
