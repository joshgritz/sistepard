Politica de Cookies

Ultima actualizacion: 21 de agosto de 2026

1. Que es localStorage

SISTEPARD utiliza localStorage (almacenamiento local del navegador) en lugar de cookies tradicionales. localStorage es una API del navegador que permite guardar pares de clave-valor en tu dispositivo de forma persistente.

A diferencia de las cookies, los datos en localStorage no se envian automaticamente al servidor con cada peticion HTTP. Solo el navegador accede a estos datos y unicamente dentro del mismo dominio.

2. Tipos de almacenamiento que utilizamos Solo esenciales

SISTEPARD no utiliza cookies de rastreo publicitario. Todo el almacenamiento es exclusivamente funcional y esencial para el funcionamiento del sistema.

ClavePropositoDuracion
[id]_sesionInformacion de sesion del usuario (cedula, nombre, rol, token JWT, expiracion). Permanece la sesion activa.24 horas
[id]_adminFlag de autenticacion para el panel de administracion.Sesion
[id]_admin_tokenToken de autenticacion del administrador para llamadas API.Sesion
[id]_admin_pinPIN de acceso del administrador (cifrado localmente).Persistente
[id]_planchasDatos de planchas de candidatos guardados localmente durante la captura de actas.Persistente

[id] se refiere al identificador del cliente/partido configurado en config.json (ej: "prm", "test-party").

3. Datos de sesion Esencial

La clave [id]_sesion almacena la siguiente informacion:

  • Cedula — numero de identificacion del usuario.
  • Nombre — nombre completo del usuario.
  • Zona y Municipio — ubicacion politica dentro de la estructura.
  • Rol — nivel de permisos dentro de la plataforma.
  • Token JWT — credencial de autenticacion para la API.
  • Expiracion — timestamp de caducidad de la sesion (24 horas).

Este almacenamiento es estrictamente necesario para que la plataforma funcione. Sin el, el usuario tendria que autenticarse en cada pagina.

4. Datos de administracion Esencial

Las claves [id]_admin, [id]_admin_token y [id]_admin_pin son utilizadas exclusivamente para el panel de administracion y permiten:

  • Mantener la sesion de administrador activa.
  • Realizar llamadas API autenticadas.
  • Recordar el PIN de acceso para evitar reingresos frecuentes.

5. Datos de planchas Esencial

La clave [id]_planchas almacena las planchas de candidatos capturadas durante el proceso de creacion de actas. Estos datos se guardan localmente para:

  • Permitir la edicion sin conexion (offline).
  • Evitar perdida de informacion durante el proceso de captura.
  • Sincronizar con la base de datos cuando se envia el acta.

6. Datos que NO almacenamos

  • No utilizamos cookies de analitica (Google Analytics, Facebook Pixel, etc.).
  • No utilizamos cookies de publicidad ni de rastreo entre sitios.
  • No compartimos datos de navegacion con terceros.
  • No utilizamos cookies de redes sociales (widgets de Facebook, Twitter, etc.).

7. Como eliminar el almacenamiento

Puedes eliminar manualmente el almacenamiento de SISTEPARD desde tu navegador:

  • Chrome: F12 > Application > Storage > Local Storage > seleccionar el dominio > click derecho > Clear.
  • Firefox: F12 > Storage > Local Storage > seleccionar el dominio > click derecho > Delete All.
  • Safari: Develop > Local Storage > seleccionar el dominio > Delete.

Tambien puedes cerrar sesion desde la plataforma, lo cual eliminara automaticamente la clave de sesion y los tokens de autenticacion.
